# 素材预览、缓存位置与项目删除

素材搜索结果直接显示命中片段所在场景的已有缓存帧，点击“播放命中片段”会从原视频跳到对应时间段。缩略图不是新生成的画面描述，也不保证是命中时刻的精确帧。视频通过支持 HTTP Range 的本地接口按需读取；部分浏览器不支持的原始编码会显示提示，仍可查看缓存画面。

全局素材库跨项目共用。场景抽帧、视频分片缓存和 SQLite 索引保存在本机，关闭程序后仍保留；ASR/OCR 的临时输入在成功后会清理，识别文本与原始 OCR 结果留在数据库中。

“设置 → 素材缓存位置”允许填写专用空目录并确认迁移。程序先备份素材库数据库，再复制并校验缓存、更新场景帧 URI，成功后移除旧缓存。原视频和索引内容不变。迁移完成后须重启 ClipAtlas，再进行解析或其他写入；此前读取和预览仍可用。迁移失败时保留原缓存及引用。环境变量直接管理的缓存目录不能被页面静默覆盖。

“删除此项目”位于顶部项目选择框旁，以及工作台的当前项目名称旁。点击后先显示删除范围，确认后删除项目文案、旁白、批次记录、规则、粗剪方案及软件管理的项目专属目录。四个项目相关数据库会先备份，删除事务失败时恢复目录。

删除项目不会清空共享素材库，也不会删除原始视频、其他项目或已经导出的外部剪映草稿。如果其他项目引用同一旁白文件，该文件保留并提示。需要清空共享索引时，仍通过素材库的独立“清空解析结果与缓存”操作并确认全局影响。

项目删除、缓存迁移与正在执行的 API 写入互斥；不改变正常解析的并发配置或 Hybrid 的召回/排序。
