# Qwen3.5 OCR P0-5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add resumable fixed-cadence OCR indexing with `qwen3.5-ocr`, absolute video timeline spans, and no new queue/database/UI.

**Architecture:** OCR samples one local video frame at a fixed cadence, sends that frame directly to the existing Bailian OpenAI-compatible endpoint as a Base64 Data URL, and persists one sample row that is both checkpoint and OCR payload. Consecutive completed samples with the same normalized non-empty text are merged into spans at read time, so no duplicate span table is introduced.

**Tech Stack:** Python 3.12, FFmpeg through existing `AsyncCommandRunner`, `httpx`, Pydantic, SQLite, Alibaba Cloud Bailian OpenAI-compatible HTTP API.

**Spec:** `docs/superpowers/specs/2026-09-05-qwen-unified-ai-stack-design.md`

## Global Constraints

- OCR model ID is exactly `qwen3.5-ocr`.
- Use the existing formal Bailian key/base URL; do not add a second OCR credential.
- OCR cadence supports backend values `0`, `1`, `5`, `10` seconds; default `5`; `0` means disabled.
- P0-5 does not add frontend UI. P0-8 exposes the cadence setting to users.
- Use the existing `library.sqlite3`; do not add another database or queue.
- One OCR sample row is both checkpoint and payload; do not add separate checkpoint or span tables.
- Consecutive identical normalized non-empty OCR text must merge into a time span; blank samples break continuity.
- Do not implement Hybrid Recall, OCR embeddings, qwen3.8 Top-K, bbox localization, document/table extraction, OSS, or Batch API in P0-5.
- Do not modify TTS, Narration, OTIO, Jianying, Human revision, SentrySearch vendor code, or historical vectors.
- Reparse creates a new OCR revision; normal retry resumes the current revision and skips completed samples.
- Temporary OCR frame files are deleted after successful persistence and retained after failure.
