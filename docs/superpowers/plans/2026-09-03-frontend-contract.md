# ClipAtlas Frontend Contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the minimum backend product/query APIs required by the Chinese local Web workbench without changing the already accepted Semantic Retrieval, Narration/TTS, RoughCut, OTIO, or Jianying core behavior.

**Architecture:** Keep the current FastAPI + SQLite architecture. Add small product-facing stores/routes around existing canonical data: projects, item/video/segment inspection, speech/narration listing, persisted local settings, and a restricted Windows shell bridge. Existing algorithmic services remain authoritative and are only consumed, not reimplemented.

**Tech Stack:** Python 3.12+, FastAPI, Pydantic v2, SQLite, pytest, pytest-asyncio, ruff, mypy.

**Spec:** `docs/superpowers/specs/2026-09-03-chinese-frontend-v0.1-design.md`

## Global Constraints

- Baseline behavior starts from commit `3c478aa65bd750658d6420d90d6ce4c96d1c41af`.
- Do not rework or rerun completed Hotfix A-E / Semantic Retrieval / Narration-TTS / RoughCut / OTIO / Jianying core tests unless a real regression is introduced by touched shared wiring.
- Human annotation remains authoritative over AI annotation; annotation PATCH continues to create a new revision and re-embed.
- Library assets, Segments, Annotations, and Embeddings remain global shared resources; Projects do not duplicate them.
- No login, registration, permissions, multi-user tenancy, video preview, editing timeline, or media-editor features.
- API keys must never be returned in plaintext by GET responses.
- Settings saved through the UI require restart in V0.1; do not add runtime hot-reload to stable providers/planners.
- Environment variables remain backwards compatible and have higher precedence than persisted UI settings.
- Empty secret inputs mean “leave unchanged”; clearing a secret requires an explicit clear flag.
- New API tests must use isolated temporary stores and must not require paid providers, FFmpeg, Jianying, Explorer, or network access.
- The system bridge must not accept arbitrary shell commands, executable arguments, URLs, or arbitrary filesystem paths from the browser.

Annotation statistics must use the same effective-selection rule as `get_effective_annotation`: HUMAN first, then highest revision/created row. Implement with a SQLite window query rather than changing annotation authority logic:

```sql
WITH ranked AS (
    SELECT
        a.*,
        ROW_NUMBER() OVER (
            PARTITION BY a.segment_id
            ORDER BY
                CASE WHEN a.origin = 'human' THEN 0 ELSE 1 END,
                a.revision DESC,
                a.created_at DESC,
                a.rowid DESC
        ) AS rn
    FROM catalog_annotations AS a
    JOIN catalog_segments AS s ON s.id = a.segment_id
    WHERE s.video_id = ?
)
SELECT
    COUNT(*) AS annotated,
    COALESCE(SUM(CASE WHEN origin = 'ai' THEN 1 ELSE 0 END), 0) AS ai_effective,
    COALESCE(SUM(CASE WHEN origin = 'human' THEN 1 ELSE 0 END), 0) AS human_effective,
    COALESCE(SUM(CASE WHEN locked = 1 THEN 1 ELSE 0 END), 0) AS locked
FROM ranked
WHERE rn = 1;
```

Get `segments_total` from `count_segments(video_id)`.

## Definition of Done

Stage A is complete only when all are true:

1. Projects can be created, listed, read, and edited persistently without deleting or copying global media assets.
2. A UI can deep-link to a LibraryItem, read video metadata, Segment count, effective AI/HUMAN annotation counts, locked count, and page through canonical Segments with current effective annotations.
3. A UI can restore project SpeechProfile and NarrationTrack history and identify active narration.
4. A UI can read/update whitelisted local configuration without receiving secrets in plaintext; blank secrets leave values unchanged; explicit clear flags clear them.
5. Persisted settings live under `./data/config/settings.json` by default and apply after restart while preserving environment-variable precedence.
6. A UI can request opening the current-process generated Jianying draft folder using only `plan_id`; it cannot submit arbitrary paths or commands.
7. A UI can launch only the configured/whitelisted Jianying executable on Windows.
8. Existing annotation correction, semantic search, narration generation, rough-cut planning, OTIO export, and Jianying export behavior remains unchanged under fresh regression gates.
9. No React/frontend code is required for Stage A acceptance.
