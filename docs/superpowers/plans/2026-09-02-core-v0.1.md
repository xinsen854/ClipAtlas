# ClipAtlas Core V0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a tested FastAPI core with canonical semantic-video models and a capability-based, multi-provider video-understanding interface that is not tied to TwelveLabs or any other vendor.

**Architecture:** The backend exposes stable ClipAtlas schemas and talks only to a provider registry. Concrete cloud/local adapters implement provider protocols later; the first batch includes a deterministic fake adapter so CI can verify the entire request path without paid API keys. Canonical timestamps and annotations are vendor-neutral and preserve future human-correction support.

**Tech Stack:** Python 3.12+, FastAPI, Pydantic v2, pytest, pytest-asyncio, httpx, Ruff, mypy, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-02-clipatlas-v0.1-design.md`

## Global Constraints

- Do not hard-code TwelveLabs, OpenAI, Gemini, Qwen, Doubao, or any other vendor into application business logic.
- `VideoUnderstandingProvider` is the common minimum contract; capability-specific operations use separate protocols.
- Canonical segment time is integer milliseconds.
- AI and future human annotations are separate immutable revisions.
- Unit and CI tests must not require paid API credentials.
- Secrets must never be committed.

### Task 2: Provider contracts, capabilities, errors, and registry

**Files:**
- Create: `clipatlas/providers/__init__.py`
- Create: `clipatlas/providers/contracts.py`
- Create: `clipatlas/providers/errors.py`
- Create: `clipatlas/providers/registry.py`
- Test: `tests/providers/test_registry.py`
- Test: `tests/providers/test_contracts.py`

**Interfaces:**
- Produces: `ProviderCapabilities`, `AnalyzeSegmentRequest`, `AnalyzeSegmentResult`, `ProviderDescriptor`, `VideoUnderstandingProvider`, `TemporalSearchProvider`, `ProviderRegistry`.
- Consumes: `SemanticAnnotation` from Task 1.

- [ ] **Step 1: Write failing capability/registry tests**

Required cases:

```python
def test_registry_rejects_duplicate_provider_name(): ...
def test_registry_filters_by_required_capabilities(): ...
def test_registry_raises_provider_not_found(): ...
```

Capability filtering must support requesting more than one required capability at the same time.

- [ ] **Step 2: Define provider contracts**

`ProviderCapabilities` contains booleans for `native_video_input`, `image_input`, `audio_understanding`, `ocr`, `temporal_search`, `semantic_segmentation`, `embeddings`, and `structured_output`.

`AnalyzeSegmentRequest` contains `video_id`, `segment_id`, `start_ms`, `end_ms`, `source_uri`, optional `frame_uris`, and optional `context`.

`AnalyzeSegmentResult` contains one `SemanticAnnotation` and provider metadata.

The base protocol exposes:

```python
@property
def name(self) -> str: ...

@property
def capabilities(self) -> ProviderCapabilities: ...

async def analyze_segment(self, request: AnalyzeSegmentRequest) -> AnalyzeSegmentResult: ...
```

`TemporalSearchProvider` is a separate runtime-checkable protocol and is not required by the base provider.

- [ ] **Step 3: Implement normalized provider errors**

Create `ProviderError` base class plus `ProviderNotFoundError`, `ProviderCapabilityError`, `ProviderRequestError`, `ProviderAuthenticationError`, and `ProviderRateLimitError`.

- [ ] **Step 4: Implement provider registry**

Registry methods:

```python
register(provider: VideoUnderstandingProvider) -> None
get(name: str) -> VideoUnderstandingProvider
list_descriptors() -> list[ProviderDescriptor]
find(required: ProviderCapabilities) -> list[VideoUnderstandingProvider]
```

`find` treats only `True` fields in `required` as mandatory.

- [ ] **Step 5: Run provider tests**

Run: `pytest tests/providers -v`
Expected: all PASS.

- [ ] **Step 6: Commit**

```bash
git add clipatlas/providers tests/providers
git commit -m "feat: add provider-neutral video understanding contracts"
```
