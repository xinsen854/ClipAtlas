# Contributing

The public source is offered under AGPLv3-or-later, with a separate
commercial licensing option held by the copyright owner.

Before submitting a pull request, open an issue to confirm the contribution
can be accepted. Contributions that may be included in the separately
licensed commercial edition require a separate contributor agreement from
the copyright holder. Do not submit code copied from projects whose license
does not permit inclusion here, or any credentials, personal data, media, or
generated runtime files.
